# Каталог: awesome-claude-skills

Источник: https://github.com/BehiSecc/awesome-claude-skills (список ссылок на скиллы; самих SKILL.md в нём нет).

## Как использовать

1. Открыть список, найти нужный скилл по категории.
2. Перейти по ссылке из списка в репозиторий скилла.
3. Забрать папку скилла целиком (SKILL.md + вспомогательные файлы) в skills/<имя-скилла>/ этого репо.
4. Добавить строку в таблицу «Взято из списка» ниже.
5. Загрузить скилл в Claude Settings. По правилу репо в Claude грузим только скиллы и MCP отсюда.
